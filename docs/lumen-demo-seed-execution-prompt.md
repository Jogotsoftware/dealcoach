# Claude Code Execution Prompt — Lumen Demo Seed (v2)

**Task:** Populate a new demo tenant in Lumen with synthetic data for the Sage Head of Sales (Melanie) demo. Joe Pacheco's real tenant is never touched. Deep-copy Chaberton's full record tree from Joe's real tenant into the demo tenant at seed time.

**Input artifact:** `lumen-demo-seed-data-spec.md` — source of truth for what data must exist. Read it cover-to-cover before doing anything else. Section numbers referenced throughout this prompt as `spec §N`.

**Output:** a fully seeded, tenant-isolated demo environment in the existing Supabase project (`npfnsyufqqhhjmtvmold`), passing all verification queries in `spec §16`.

---

## Operating Principles

Before any tool call, internalize these:

**1. Joe Pacheco's real tenant is sacrosanct.** Zero writes — no INSERT, UPDATE, or DELETE against any record where `org_id != <demo-tenant-id>`. Reads only, and only against records needed to identify Chaberton for the deep-copy. If you find yourself writing SQL that targets a non-demo `org_id`, stop.

**2. Demo tenant is fully self-contained.** All synthetic data + Chaberton copy lives in the new demo tenant. RLS isolates the two tenants naturally.

**3. Two markers, two scopes.** Every demo-tenant row carries `metadata->>'seed_origin'` set to either `'demo_synthetic_v1'` (generated by seed) or `'chaberton_copy_v1'` (deep-copied from real tenant). This enables independent re-runs.

**4. Schema first, data second.** Verify every column, enum value, and constraint you depend on exists in the current schema before inserting data that uses it. Use `list_tables` and inspect columns. Migrations before inserts.

**5. Halt on verification failure.** End-of-phase verification queries must match expected counts within tolerance. Halt and report on anomalies rather than proceeding.

**6. Use Supabase MCP tools directly.** Load via `tool_search` at session start: `apply_migration`, `execute_sql`, `list_tables`, `list_extensions`. Use `apply_migration` for DDL (recorded in migration history), `execute_sql` for inserts/updates/queries.

**7. Project conventions** (from CLAUDE.md and operating memory):
- Multi-tenant RLS on every new table — no exceptions
- Discovery-dependent fields default to `'Unknown'` (string), not NULL
- First-class relational tables, never JSONB blobs on parent records
- pgvector references: `extensions.vector(1536)` and `extensions.vector_cosine_ops`
- `.catch()` is NOT supported on Supabase query builders — use `try/catch` in any helper code

**Most precision-critical phase.** Reads from real tenant, writes to demo tenant.

### 2.5.1 UUID mapping setup

Initialize an in-memory map for this session:

```
uuid_map: { real_uuid → new_uuid }
```

Helper function (pseudocode):
```
def new_id(real_id):
  if real_id not in uuid_map:
    uuid_map[real_id] = generate_uuid()
  return uuid_map[real_id]
```

Pre-register the deal's owner mapping:
- `uuid_map[<joe-pacheco-real-id>] = <demo-joe-id>`
- `uuid_map[<joe-real-org-id>] = <demo-tenant-id>` (for any rows that have org_id directly)

### 2.5.2 Copy in FK dependency order

For each table in `spec §13.2`, in order:

1. **Read** all source rows tied to Chaberton (by `deal_id = <chaberton_real_id>`, or by FK chain to it for company-linked tables).
2. **Transform** each row:
   - `id = new_id(row.id)`
   - `<fk_columns> = new_id(row.<fk_column>)` for every FK
   - `org_id = '<demo-tenant-id>'`
   - `owner_id = '<demo-joe-id>'` (where the column exists)
   - `metadata = COALESCE(row.metadata, '{}'::jsonb) || '{"seed_origin": "chaberton_copy_v1"}'::jsonb`
3. **Insert** into demo tenant. Confirm row count matches source.

**Special handling:**

- `deal_context_chunks`: the `embedding` column (pgvector) copies as-is. Don't regenerate.
- `conversations`: preserve `processed`, `ai_summary`, `ai_raw_response`, and all transcript content exactly.
- `company_profile`: this is the parent of `deals` for Chaberton — copy first.
- `contacts`: copy all contacts linked to Chaberton's company OR linked via `deal_team_contacts` to Chaberton's deal.
